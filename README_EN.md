# Silivid

The English README is the [repository homepage](README.md).

Silivid is a video player and video enhancement tool for macOS on Apple Silicon, in development, with no usable version yet. It is a modified fork of [Veyra](https://github.com/Likely7/Veyra-NRVideo), distributed under [GPL-3.0](LICENSE).
